# Community contributions

Thank you to the contributors who investigated TikTok's changing Favorites interface.

- [fathulfahmy, PR #6](https://github.com/gabireze/tiktok-all-favorite-videos-remover/pull/6): identified a changed favorite-button selector.
- [masprodv1, PR #7](https://github.com/gabireze/tiktok-all-favorite-videos-remover/pull/7): investigated TikTok's feed-style Favorites view and proposed sequential processing and clearer error feedback.
- [chatterchats, PR #4](https://github.com/gabireze/tiktok-all-favorite-videos-remover/pull/4): proposed browser portability and extracted the locale and currency maps. The map extraction remains in the current popup.

The current extension scans the Favorites grid and removes confirmed items through TikTok's web endpoint. The earlier click-based implementations remain credited in the merge history without replacing this workflow.
